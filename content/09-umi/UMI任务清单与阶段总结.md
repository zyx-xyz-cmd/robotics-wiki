# UMI 毕业设计：任务清单与阶段总结

> 课题：基于UMI的机器人示范采集与操作学习系统设计与实现 本文用于持续更新任务进度、验收结果与学习记录。所有任务默认未验收，不代表实际尚未开展。

## 1. 最终目标

以 LightUMI 为基础，制作一套无需机器人本体参与采集的手持示范装置，完成桌面抓取与放置任务的采集、处理、策略训练和真机执行闭环。重点是设备和系统贯通，不强制提出新模型。

``` mermaid
flowchart TD
 A[手持夹爪示范] --> B[图像、位姿、开度及时间戳]
 B --> C[标定、同步、筛查与重采样]
 C --> D[示范数据集]
 D --> E[模仿学习策略训练]
 E --> F[动作映射与真机执行]
 F --> G[测试、评价与优化]
```

## 2. 任务清单

### M1 文献学习与方案设计

-   [ ] 阅读 UMI 原始论文，理解无本体示范采集原理。
-   [ ] 阅读 LightUMI 文档、安装说明、硬件清单和源码，记录版本。
-   [ ] 学习 OpenCV、ArUco、相机标定、齐次变换与模仿学习。
-   [ ] 确认实验室可用机械臂、夹爪、相机、计算资源与控制接口。
-   [ ] 确定桌面抓取放置任务、数据字段、坐标系与评价指标。

**验收：** 总体架构图、设备选型依据、数据接口说明、开题材料。

### M2 采集设备制作

-   [ ] 核对 LightUMI 结构文件及物料清单，确定采购预算。
-   [ ] 选型手持夹爪、相机和位姿采集模块。
-   [ ] 完成 CAD 设计、加工或打印、装配。
-   [ ] 检查夹爪行程、相机视野、标记可见性、安装刚度。
-   [ ] 完成视频采集与手动启停测试。

**验收：** 一套可工作的手持设备、结构文件、BOM 与装配说明。

### M3 相机标定与夹爪开度测量

-   [ ] 制作或准备标定板及 ArUco 标记。
-   [ ] 获取相机内参、畸变参数与重投影误差。
-   [ ] 实现 ArUco 检测并确认标记坐标系。
-   [ ] 建立标记测量值到实际夹爪开度的映射。
-   [ ] 使用尺或卡尺采集不同开度参考值，统计测量误差。
-   [ ] 检查遮挡、运动模糊及标记丢失等异常情况。

**验收：** 实时开度曲线、标定文件、参考值与测量值对照表。

### M4 位姿采集与坐标变换

-   [ ] 对比视觉 SLAM 与外部跟踪方案，依据实际设备选定一种。
-   [ ] 获取连续的六自由度位置与姿态，检查尺度与跟踪稳定性。
-   [ ] 标定相机与夹爪工具坐标系之间的固定变换。
-   [ ] 实现世界系、相机系、示范工具系及机器人坐标系转换。
-   [ ] 使用已知位移或参考跟踪设备评价位姿误差。
-   [ ] 可视化平移与旋转轨迹，记录跟踪失败情况。

**验收：** 带时间戳的 6DoF 轨迹、变换参数、误差记录。

相机位姿转换为工具位姿的示意公式（上标为参考坐标系）：

$$
{}^WT_G = {}^WT_C\,{}^CT_G
$$

### M5 同步采集与数据处理

-   [ ] 基于 LightUMI 共享软件时钟记录各数据源时间戳，核对实际接口。
-   [ ] 实现采集启停、会话编号、视频及元数据保存。
-   [ ] 对齐图像、位姿和开度；测量时间对齐误差，不能仅假设同步。
-   [ ] 实现固定频率重采样、异常筛查与丢帧处理。
-   [ ] 实现回放功能，同时展示视频、轨迹和开度。
-   [ ] 先完成少量试采集，确认数据质量后再批量采集。

**验收：** 可重复运行的数据采集与处理程序，以及完整试采集记录。

建议数据字段（不是已核验的 LightUMI 原生格式）：

  字段            含义
  --------------- ----------------------------------
  episode_id      示范编号
  timestamp       时间戳
  image           RGB 图像或视频索引
  position        三维位置
  orientation     姿态，例如四元数及明确的分量顺序
  gripper_width   夹爪开度
  valid           数据有效性标记

### M6 数据集构建

-   [ ] 确定任务开始、结束及有效示范判据。
-   [ ] 覆盖至少 3 种物体初始位置。
-   [ ] 采集不少于 100 条有效示范，保留失败记录。
-   [ ] 按完整 episode 划分训练和测试数据，避免相邻帧泄漏。
-   [ ] 保存原始记录、处理脚本、数据版本、单位及坐标约定。

**验收：** ≥100 条有效示范，≥3 种初始位置，可加载的数据集。

### M7 模仿学习训练

-   [ ] 选择成熟开源策略（建议 Diffusion Policy，最终依据接口和资源确定）。
-   [ ] 阅读模型数据格式，适配观测、动作、归一化及动作序列。
-   [ ] 检查图像与目标动作的时间对应关系、单位和坐标系。
-   [ ] 小数据试训练，验证数据加载、前向传播和 checkpoint 保存。
-   [ ] 正式训练，保存配置、随机种子、损失曲线和模型权重。
-   [ ] 加载模型完成离线预测，检查动作轨迹及夹爪输出。

**验收：** 可复现的训练命令、模型权重、离线推理记录。

### M8 真机部署

-   [ ] 确认机械臂实际型号、控制接口与可用工作空间。
-   [ ] 建立示范工具到机器人末端的动作映射。
-   [ ] 处理坐标系、尺度、姿态表示、夹爪行程及控制频率。
-   [ ] 实现工作空间、速度及行程限制和异常停机机制。
-   [ ] 先进行离线或仿真验证，再在实验室授权与指导下低速真机调试。
-   [ ] 完成从实时观测到策略推理再到抓取放置的闭环。

**验收：** 真机任务执行记录、推理程序及演示视频。

### M9 实验评价

-   [ ] 统一测试条件、成功判据与超时标准。
-   [ ] 开展不少于 20 次独立真机测试。
-   [ ] 统计成功率、执行时间、推理耗时与失败原因。
-   [ ] 汇总数据完整性、时间对齐误差、开度误差和位姿误差。
-   [ ] 分析失败来源并开展针对性优化，保留优化前后数据。

成功率 = 成功次数 / 总测试次数 × 100%。任务书未规定最低成功率或测量误差阈值，需根据设备条件确定并如实报告。

### M10 成果整理

-   [ ] 整理论文、图表、实验结果与参考文献。
-   [ ] 提交结构设计文件、BOM、标定方法及操作说明。
-   [ ] 整理可运行代码、数据处理脚本、配置和实验记录。
-   [ ] 制作完整演示视频与答辩材料。


## 3. 当前阶段学习总结

UMI 是示范采集接口，不是策略模型。其价值是将示范采集与机器人本体解耦。图像用于提供视觉观测，位姿用于描述手持工具运动，开度用于描述夹爪操作。通过标定和同步，可以将这些信息组织为模仿学习需要的观测与动作序列。DP 等模型学习从观测到动作的映射，机器人控制接口负责执行动作。

目前具体组件型号、预算、LightUMI 版本、位姿跟踪方案与实际完成进度尚待确认。本总结为学习认识与实施计划，不是已完成实验报告。
